# Flight Booking Analytics Dashboard – Power BI

## Project Overview
An interactive Power BI dashboard designed to analyze flight bookings, passengers, booking values, refunds, airline performance, and flight operations.

**Project Status:** Work in Progress

## Tools & Technologies
- Microsoft Power BI
- Microsoft Excel
- Power Query
- DAX

## Dashboard Pages
1. Executive Overview
2. Revenue Analytics
3. Booking & Cancellation Analysis – Planned
4. Flight Performance – Planned

## Key Features
- KPI cards
- Interactive slicers
- Airline-wise analysis
- Revenue and refund analysis
- Booking status distribution
- Data cleaning and transformation
- DAX-based calculations

## Dataset
The project uses a synthetic flight booking dataset containing 100 sample records and 20 original columns.

## How to Use
1. Download or clone this repository.
2. Open the `.pbix` file using Power BI Desktop.
3. If prompted, reconnect the Excel dataset.
4. Explore the dashboard using the slicers and visuals.
